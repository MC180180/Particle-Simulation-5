## 场景参数与全局控制
> 左下角的“参数调整”面板控制着整个沙盒宇宙的基础物理法则和存档管理。

### 🌍 全局物理参数
- **场景大小(倍率缩放)**: 控制物理引擎碰撞网格的空间尺度。更改此数值可以改变你能建造的结构上限。
- **子步 (Substeps)**: **【性能与稳定性核心】** 控制物理引擎每帧进行几次求解计算。增大该值会让刚体（高连接强度的物质）更稳定、不易穿模弹飞，但会显著增加运算负担。
- **光子子步**: 专门控制光线碰撞的精度。如果你的光子速度极快导致“穿墙”，请调高此参数。
- **时间步长**: 控制整个模拟世界的时间流逝速率。调低可观察慢动作微观反应，调为 0 可完全暂停物理流逝。
- **空气阻力 (动能损失)**: 场景的全局摩擦力，代表每秒损失的动能比例。越高则物体越快静止。
- **施加电荷**: 配合“Alt+左键”快捷键使用，决定你一次点击能给区域内的粒子灌注多少电荷。
- **重力 (g)**: 整个场景的基准重力加速度。

### 🧹 清理与场景库
在参数下方是一系列对场景状态进行管理的核心按钮：
- **🗑⬡ (非钉)**: 瞬间清除场景内所有在乱跑的“非固定”粒子（常用于清理反应残渣，同时保留墙壁和容器底座）。
- **🗑⬢ (粒子) / 🗑〇 (源)**: 分别用来一键清空所有的物理粒子，或所有的场源（光源/发生器）。
- **🗑 ALL (全部)**: 彻底清屏，一切归零。
- **■↓ (存档) / □↑ (读档)**: 保存和加载整个沙盒宇宙的状态（包含所有粒子的连接、温度、发光体等）。
- **✦↓ (存模型) / ✧↑ (模型库)**: 局部蓝图系统，将你精心拼装出来的机器或化学反应炉保存为一个结构模型，方便日后随时拖入任何场景。
