#  粒子模拟 5 (Particle Sim 5)

这是一款基于 **Rust + WGPU (Vulkan)** 开发的高性能 GPU 颗粒物理学模拟沙盒引擎。得益于全 GPU 并行计算（Compute Shader）架构，程序能够在一个极低的性能开销下，在你的显卡内实时计算**最多一百万个粒子**的流体动力学、刚体力学与热辐射交互。


---

##  玩法与交互 (Gameplay)
你可以在无边界的二维宇宙中扮演“造物主”。利用左侧完备的交互面板和右键快捷操作，自由调配各类物质，看着它们在你创造的引力、外力乃至自身的结构张力中崩塌或演化。

###   操作方式 (Controls)
* **生成粒子 (左键)**：根据面板选中的模式（点、圆、直线、画笔），在鼠标位置生成粒子。
* **擦除粒子 (Shift + 左键)**：按下 Shift 修改生成状态，化身为无敌橡皮擦，涂抹清空任何接触到的物质。
* **刚体移动 (鼠标拖拽)**：将鼠标互动模式切为“引力抓取 / 精准拖拽”，可以直接拽动庞大的物理结构，感受其强烈的重力与惯性沉浮感。
* **快捷右键菜单 (右键)**：无需长途跋涉到左侧栏，在屏幕中右击随时唤出悬浮交互面板更改材质。
* **缩放与漫游**：滚轮缩放视图，按住鼠标中键或右键拖拽以移动画布。

##  主要功能板 (Features)
1. **全自由物质库**
   * 从轻盈飘摇的【气】到深沉聚合的【水】。
   * 从软弹拉扯的【泥】到绝对静止的宇宙【地基】。
   * 材质具有相互作用（如受热、冷却变化）。
   
2. **结构预设蓝图库**
   * 厌倦了一点点搭积木？使用蓝图模式将建造好的雄伟结构一键存为“印章”，并在任何时刻作为**预设模型**粘贴至世界。

3. **上帝之手系统**
   * 包括：**时间暂停**、**强行修改局部温度**、**改变全局重力大小与方向**、甚至放置可以永久提供向心引力的 **黑洞源**。

4. **实时保存读档**
   * 一键保存整个宇宙当前的微观状态（坐标、速度、链接、温度），生成存档文件，随时分享或随时回溯。

---

##  视觉效果 (Visual Effects)
* **速度映射**：当系统运动剧烈时，粒子的色彩会根据其内部动能自动漂移并发生亮度增溢。
* **简约渲染**：利用 WGSL 原生实现大规模实例化绘制（Instanced Drawing），摒弃重度图形渲染负担，呈现具有科幻电子风格的终极极客物理实验台。
* **链接可视化**：刚体、软体粒子之间拉扯的“物理弹簧链”会高亮显示，完美展示承重节点和应力破坏。
